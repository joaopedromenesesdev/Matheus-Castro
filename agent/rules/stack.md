# Diretrizes Técnicas - Stack Estática

## Tecnologias Obrigatórias
- Estrutura: HTML5 semântico (apenas um ficheiro index.html principal).
- Estilo: CSS3 puro moderno (em styles.css) usando CSS Custom Properties (variáveis) para toda a paleta de cores e tipografia.
- Interatividade: JavaScript Vanilla (em main.js) para animações suaves ao scroll (Intersection Observer) e filtros da timeline.
- PROIBIDO: React, Vue, Next.js, frameworks pesados ou bibliotecas externas desnecessárias.

## Identidade Visual - Private Wealth Management
- Público-alvo: Clientes Private Banking / Alta Renda.
- Paleta:
  - Fundo principal: #0A0A0C (Dark Slate refinado).
  - Superfície dos cartões: #141418 com bordas subtis em #222228.
  - Tipografia / Títulos: #F5F5F7 com destaque em dourado discreto (#C5A880) e laranja institucional sutil (#EC7000) apenas em detalhes mínimos.
- Tipografia: Serifada editorial para cabeçalhos (Playfair Display via Google Fonts) e sem serifa neutra para texto (Inter).
